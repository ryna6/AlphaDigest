# Data Sources

Sources include Unusual Whales featured news, broader news feed, economic calendar, earnings, dark pool, whale trades, insider trades, Capitol Trades, sec-api.io 13F, Finnhub four heatmap keys, Twelve Data, CoinGecko, FRED, CBOE market statistics, AAII sentiment, and optional HormuzTracker with attribution.

Oil prices: WTI and Brent should use Finnhub, Twelve Data, FRED where appropriate, or another available market data provider. Oil historical charts should use Twelve Data if available. Oil macro context can use FRED where appropriate.
